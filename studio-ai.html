Studio AI

Ruang praktik mendesain tugas & asesmen HOTS bersama AI. Semua aktivitas terekam otomatis untuk dokumentasi PKM.

Rujukan materi: 1 · HOTS & Autentik 2 · AI & Prompting 3 · Studi Kasus
  1. 1

    Buka aistudio.google.com/apikey di browser (boleh HP).

  2. 2

    Login memakai akun Google Anda, lalu setujui Terms of Service bila diminta.

  3. 3

    Klik tombol Create API key (atau Get API key → Create API key).

  4. 4

    Pilih project yang ada, atau biarkan Google membuat project baru otomatis.

  5. 5

    Klik Copy pada kode yang muncul (dimulai dengan AIza…).

  6. 6

    Kembali ke halaman ini, tempel di kolom API Key pada Langkah 2, lalu klik Simpan & Uji.

⚠️ Jaga kerahasiaan. API Key seperti kata sandi. Jangan dibagikan atau dipasang di grup WhatsApp.

🔒 Aman. Key hanya disimpan di browser Anda sendiri (localStorage), tidak dikirim ke panitia maupun ke Google Sheet.
